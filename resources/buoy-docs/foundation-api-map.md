# Installed foundation mapping

Summary: Explicit names and implementation routes for every declared public symbol in this surface.

This is an inventory of the supported subset, not a claim that the historical framework is implemented completely. Entries name real adapter implementations. Native inherited members remain available under their native contracts. A name mapping alone does not change argument order, indexing, coercion, event ordering or unsupported-platform behavior.

The complete machine-readable mapping ships as `legacy-api-map.json` (also `notes/legacy-api-map.json` in source). [Contracts and limitations](index.md).
